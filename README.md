# InfluencrIn 🎯

InfluencrIn is a full-stack influencer discovery and review platform built with a modern tech stack. 
It includes a **React (Vite)** client, **Node.js (Express)** server, and a **PostgreSQL** database. 
The app currently uses dummy data for testing and development purposes.

## 🗂️ Project Structure

When you clone this repository, you'll get the following directory structure:

influencrin/
├── client/ # Frontend (React)
└── server/ # Backend (Node.js, Express)
